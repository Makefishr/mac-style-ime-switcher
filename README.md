# Mac-style IME Switcher

适用于 Windows 10/11 的 CapsLock 中英文切换工具。程序常驻系统托盘，短按 CapsLock 切换输入法，长按进入或退出大写锁定。

## 下载与快速开始

1. 从 [Releases](https://github.com/Makefishr/mac-style-ime-switcher/releases/latest) 下载 `MacStyleIME.exe`。
2. 直接运行，无需安装。
3. 右键托盘图标打开“设置”。
4. 如果需要在管理员 CMD、Windows Terminal 或其他管理员应用中切换，请启用“以管理员身份运行”。

首次启用管理员模式时，Windows 会显示 UAC 请求；取消或启动失败时，MacStyleIME 会回到普通模式继续运行。同时启用开机自启后，登录时由启动项拉起当前用户的最高权限计划任务，后续登录不再请求 UAC。手动启动 exe 仍可能请求 UAC。

## CapsLock 行为

- **短按**：执行设置中选择的输入法切换方式。
- **长按 1 秒后松开**：进入或退出大写锁定，CapsLock 指示灯会同步变化。
- **普通 Shift 组合不受影响**：例如 `Shift+1` 仍可正常输入 `!`。

程序始终拦截 `Win+Space`，默认也拦截 `Ctrl+Space`，后者可在设置中关闭以保留编辑器代码补全。默认关闭 Windows 的 `Ctrl+Shift` / `Alt+Shift` 语言切换设置，不吞掉 Shift，因此 `Ctrl+Shift+T`、`Ctrl+Shift+Esc` 等组合仍正常工作。

## 两种切换方式

### 切换键盘输入法

在英文键盘和微软拼音键盘之间切换。这是默认方式，需要先在 Windows 中添加中文和英文键盘布局。

### 仅切换微软拼音内部中英文

保持微软拼音键盘不变，只切换其内部中文/英文模式。使用前请先切到微软拼音。

该方式使用 Windows IMM 兼容接口，不发送 Shift，也不切换键盘布局。它适用于已经支持该接口的输入框，但不能保证覆盖所有现代 TSF、WinUI、UWP 或浏览器输入框。

## 设置

- **以管理员身份运行**：允许 MacStyleIME 处理相同或更低权限应用中的按键，包括管理员应用。
- **输入法切换方式**：在两种 CapsLock 切换行为之间选择。
- **关闭系统 Ctrl+Shift / Alt+Shift 语言切换**：首次修改前保存原值，关闭该选项时恢复。此系统设置在程序退出后仍然保留；若未生效，请注销后重新登录。备份保存在下述设置目录中，请在恢复前保留它；若备份丢失，程序会提示在 Windows 高级键盘设置中重新指定快捷键。
- **拦截 Ctrl+Space**：默认开启；关闭后可用于编辑器代码补全。`Ctrl+Shift+Space` 和 `Ctrl+Alt+Space` 会放行。
- **开机时自动运行**：两种模式都写入当前用户的 Run 启动项，所以会显示在任务管理器的“启动应用”中，在那里禁用也会生效，设置里的开关会同步显示为关闭。管理员模式另建一个没有触发器、只供按需运行的最高权限计划任务：登录时启动项先以普通权限启动，再运行这个任务拉起管理员实例，不弹 UAC；任务无法运行时本次以普通模式继续。更换自启方式或移除管理员任务时可能请求 UAC。

设置和诊断日志保存在 `%LOCALAPPDATA%\MacStyleIME`。

设置界面保留已保存的自启选项；若系统设置或自启注册失败，会说明尚未生效的部分，修复后可重新保存。切换管理员模式时取消 UAC，会恢复普通模式，并按保存的自启选项更新 Run 启动项；已有最高权限任务的移除仍需要管理员权限。

## 命令行

```text
MacStyleIME.exe              运行并驻留系统托盘
MacStyleIME.exe --install    添加当前用户开机自启
MacStyleIME.exe --uninstall  移除当前用户开机自启
MacStyleIME.exe --help       显示帮助
```

`--install` 遵循已保存的管理员模式设置；`--uninstall` 移除 Run 启动项和本程序为当前用户创建的自启任务。管理计划任务时会按需请求 UAC。

## 兼容边界

- 管理员模式不会绕过 Windows 安全桌面，也不能作用于登录界面、锁屏或 UAC 确认窗口。
- 管理员自启任务会以最高权限运行 exe 当前所在位置的文件。若 exe 放在当前用户可写的目录（如下载文件夹或桌面），同一用户下的其他程序可以替换它，从而不经 UAC 获得管理员权限。长期使用管理员自启时，建议把 exe 放到 `C:\Program Files\MacStyleIME` 这类需要管理员权限才能改写的目录后再开启。
- 微软拼音内部模式依赖目标输入框对 IMM 兼容消息的支持；不支持时会保持当前状态。
- 程序只处理当前交互桌面的键盘输入。
- 钩子使用阻塞消息循环，每 60 秒在所属线程先卸载再重装，缓解 Windows 静默移除钩子后无法切换的问题。恢复前可能短暂无法接管按键；持续的回调超时仍需排查日志与系统负载。

## 隐私

- 不包含遥测、联网、上传或自动更新逻辑。
- 键盘钩子只瞬时处理完成切换所需的虚拟键状态，不记录输入内容、剪贴板或窗口标题。
- 诊断日志包含启动、切换结果、错误和本地路径，不包含键入文本。

## 从源码构建

需要 64 位 Python 3.12。在仓库根目录运行：

```bat
build_ime.bat
```

构建脚本会创建全新的隔离环境，通过 `requirements-build.txt` 校验所有直接和间接依赖的版本与 SHA-256，并在成功后生成根目录下的 `MacStyleIME.exe`。

更新构建依赖时，先修改 `requirements-build.in`，再在受控的 Windows x64 / Python 3.12 环境中重新生成并审查锁文件。
