# Mac-style IME Switcher

用 CapsLock 在 Windows 10/11 上切换中英文：短按切换，长按开启大写锁定。程序常驻系统托盘，无需安装。

[下载 exe](https://github.com/Makefishr/mac-style-ime-switcher/releases/latest) · [更新记录](https://github.com/Makefishr/mac-style-ime-switcher/releases)

## 开始使用

1. 下载 `MacStyleIME.exe`，放到准备长期使用的文件夹。需要管理员自启时，先阅读[管理员模式](#管理员模式)中的存放要求。
2. 双击运行。默认切换方式需要 Windows 已添加英文键盘和微软拼音。
3. 短按 CapsLock，确认能在两种键盘之间切换。
4. 右键托盘图标，打开“设置”，按需调整后点击“保存”。退出程序也在托盘菜单中操作。

首次运行默认会关闭 Windows 的 `Ctrl+Shift` / `Alt+Shift` 语言切换快捷键，并拦截 `Ctrl+Space`。需要保留这些快捷键时，在[设置](#设置)中关闭对应选项。

## 按键操作

| 操作 | 效果 |
| --- | --- |
| 短按 CapsLock | 按所选方式切换中英文 |
| 按住 CapsLock 约 1 秒后松开 | 开启大写锁定，点亮 CapsLock 指示灯 |
| 大写锁定时再按 CapsLock | 关闭大写锁定 |

程序运行时始终拦截 `Win+Space`。普通 Shift 组合仍可使用，例如 `Shift+1`、`Ctrl+Shift+T` 和 `Ctrl+Shift+Esc`。

## 两种切换方式

- **切换键盘输入法（默认）**：在英文键盘和微软拼音之间切换。使用前需在 Windows 中添加这两种键盘。
- **仅切换微软拼音的中/英文模式**：保持微软拼音键盘，只切换其内部中英文状态。使用前先切到微软拼音。

第二种方式依赖输入框对 Windows IMM 兼容接口的支持，不发送 Shift。部分现代应用、UWP 或浏览器输入框可能不支持；切换无效时，改用“切换键盘输入法”。

## 设置

| 选项 | 用途 |
| --- | --- |
| 输入法切换方式 | 选择上面的两种切换方式之一 |
| 关闭系统语言切换快捷键 | 默认开启，关闭 Windows 的 `Ctrl+Shift` / `Alt+Shift` 语言切换；关闭此选项可恢复原设置 |
| 拦截 Ctrl+Space | 默认开启；关闭后可在编辑器中使用该键补全代码。`Ctrl+Shift+Space` 和 `Ctrl+Alt+Space` 始终放行 |
| 以管理员身份运行 | 用于在管理员应用中切换输入法，见[管理员模式](#管理员模式) |
| 开机时自动运行 | 登录当前 Windows 用户后启动，见[开机自启](#开机自启) |

语言切换快捷键属于 Windows 系统设置，退出 MacStyleIME 后仍会保留。程序首次修改前会备份原值；恢复完成前请保留[数据目录](#数据与隐私)中的备份。若提示尚未生效，请注销后重新登录；备份丢失时，需到 Windows 高级键盘设置中重新指定快捷键。

保存失败时，窗口会提示未生效的部分。按提示处理后重新保存，不要只凭开关位置判断是否已经生效。

## 管理员模式

只在管理员 CMD、Windows Terminal 或其他管理员应用里无法切换时，开启“以管理员身份运行”。首次开启会请求 UAC 授权；取消或启动失败时，程序继续以普通模式运行。设置窗口顶部显示当前实际运行模式。

同时开启自启后的登录行为见[开机自启](#开机自启)。手动双击 exe 时，已保存的管理员模式仍可能触发 UAC。关闭管理员模式后，当前管理员实例会继续运行，下次启动才使用普通模式。

**开启管理员自启前，请把 exe 放到普通权限程序不能改写的目录**，例如 `C:\Program Files\MacStyleIME`，并确认该目录没有额外授予普通用户写权限。管理员自启会以最高权限运行已登记路径中的文件；若放在桌面、下载文件夹等当前用户可写的位置，同一账户下的其他程序可能替换它并获得管理员权限。

管理员模式仅适用于当前交互桌面，不能用于登录界面、锁屏或 UAC 安全桌面。

## 开机自启

在设置中开启“开机时自动运行”并保存后，可在任务管理器的“启动应用”中找到 MacStyleIME。

- **普通模式**：登录后以普通权限运行。
- **管理员模式**：配置时可能请求 UAC；配置成功后，登录时通过当前用户的按需计划任务启动管理员实例，不弹 UAC。任务无法运行时，本次以普通模式继续。

在任务管理器中禁用后，下次登录不会启动；重新打开设置窗口时，自启开关会显示为关闭。保存其他设置不会重新启用它；需要恢复时，在程序内重新开启自启并保存，或在任务管理器中启用。

自启使用 exe 的所在路径。移动或替换到其他文件夹后，请从新位置运行并重新配置自启。关闭自启会移除启动项和本程序为当前用户创建的任务；移除管理员任务时可能请求 UAC。

## 常见问题

- **管理员窗口里不能切换**：检查设置窗口顶部的实际运行模式；需要时开启[管理员模式](#管理员模式)并完成授权。
- **微软拼音内部中英文切换无效**：先确认当前使用微软拼音；目标输入框可能不支持此方式，可改用“切换键盘输入法”。
- **登录后没有自动运行**：先检查任务管理器是否禁用了 MacStyleIME，再从 exe 所在位置打开设置并重新配置自启。
- **运行一段时间后 CapsLock 失效**：尝试从托盘退出后重启，查看[诊断日志](#数据与隐私)。程序会定期重装键盘钩子以尝试恢复，持续失效仍需排查。

## 数据与隐私

设置、系统快捷键备份和诊断日志保存在 `%LOCALAPPDATA%\MacStyleIME`。可从设置窗口点击“打开日志文件夹”访问。

- 程序没有遥测、联网、上传或自动更新逻辑。
- 键盘钩子处理切换所需的按键状态，不记录键入文本、剪贴板或窗口标题。
- 诊断日志包含启动、切换结果、错误和本地路径。提交问题前，请检查日志中的用户名和路径，按需打码。

## 命令行

```text
MacStyleIME.exe              运行并驻留系统托盘
MacStyleIME.exe --install    添加当前用户开机自启
MacStyleIME.exe --uninstall  移除当前用户开机自启
MacStyleIME.exe --help       显示帮助
```

`--install` 使用已保存的管理员模式设置；配置或移除管理员任务时会按需请求 UAC。登录用的内部参数由程序管理，无需手动添加。

## 从源码构建

需要 Windows、64 位 Python 3.12 及 Windows Python Launcher。在仓库根目录运行：

```bat
build_ime.bat
```

脚本会从 PyPI 下载依赖，在全新的隔离环境中按 `requirements-build.txt` 校验版本与 SHA-256，然后生成仓库根目录下的 `MacStyleIME.exe`。运行前请备份需要保留的旧 exe，脚本会先删除原输出文件。

更新构建依赖时，先修改 `requirements-build.in`，再在受控的 Windows x64 / Python 3.12 环境中重新生成并审查锁文件。
