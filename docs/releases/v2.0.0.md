# v2.0.0：在任务管理器中管理自启

## 主要更新

- **自启出现在“启动应用”中。** 开启自启后，普通模式和管理员模式都能在任务管理器中查看、禁用或启用。在那里禁用后，重新打开程序设置也会显示为关闭；保存其他设置不会重新开启自启。
- **管理员模式登录时不弹 UAC。** 完成自启配置后，登录时自动启动管理员实例。管理员任务无法运行时，本次以普通模式继续，不自动请求提权。手动打开 exe 仍可能请求 UAC。
- **重新设计设置窗口。** 使用 Windows 11 风格的卡片、开关和单选项，跟随系统浅色或深色主题，显示当前实际运行模式，并提示需要授权或注销才能生效的设置。
- **可恢复系统语言切换快捷键。** 可关闭 Windows 的 `Ctrl+Shift` / `Alt+Shift` 语言切换，减少与 CapsLock 的冲突；修改前备份原值，关闭选项时恢复。需要编辑器代码补全时，可单独关闭“拦截 Ctrl+Space”。
- **调整图标与文件信息。** 图标居中绘制，适配不同显示尺寸；exe 文件属性中加入产品版本和公司名称。

## 升级与使用

1. 从旧版本的托盘菜单退出程序，再运行新的 `MacStyleIME.exe`。
2. 打开设置，确认切换方式、管理员模式和自启选项。旧版自启配置会在启动时检查并迁移；需要修改管理员任务时，按提示完成授权。
3. 开启自启后，可在任务管理器的“启动应用”中确认状态。移动 exe 到其他文件夹后，请从新位置运行并重新配置自启。

使用管理员自启前，请按 [README 的存放要求](https://github.com/Makefishr/mac-style-ime-switcher/blob/main/README.md#管理员模式)选择 exe 目录，避免其他普通权限程序替换该文件后取得管理员权限。

微软拼音内部中英文切换仍取决于目标输入框支持；切换无效时，改用“切换键盘输入法”。完整用法见 [README](https://github.com/Makefishr/mac-style-ime-switcher#readme)。
